GitHub: sopi22 · IT student building small tools that check whether things really work the way they say they do.

StayGone (Windows)

Keeps removed Windows bloatware gone. Windows reinstalls apps like Xbox or Clipchamp after updates; StayGone removes them again automatically, or asks you first. Nothing to install.

DownloadHow to use

RepoNudge (Windows / Linux)

Gives you a nudge when one of your GitHub repos needs attention: failing tests, unreleased work, waiting issues, each with a plain "what to do" line.

DownloadHow to use

chronobot (Telegram)

A Telegram reminder bot that never guesses your time. If a time is unclear, it asks. Nothing to download: message @ChronoSopiBot on Telegram.

About chronobot

polygraph (Linux)

A lie detector for AI model files: opens a model file in a locked-down sandbox and checks what it says it is against what it actually does.

DownloadProject page

caveat-keeper

Catches the warnings that quietly disappear from project notes written by AI helpers.

phone-tryout (Android)

Tries things out on a real Android phone instead of trusting what the phone reports.
